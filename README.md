# 旁座 SideSeat

> 看着你的屏幕陪你一起看；你叫它看什么，它就去看一眼。

> **非官方（Unofficial）**：这是社区项目，与 DeepSeek 官方无隶属关系，不代表官方立场，也未使用 `@deepseek-ai/*` 命名空间。
>
> **安全边界先读**：DSH 插件以宿主进程权限运行，**DSH 不提供插件沙箱**。旁座会截屏、起 PowerShell / ffmpeg 子进程、读写插件自己的数据目录。完整清单见 [SECURITY.md](./SECURITY.md)。

旁座是一个住在 DeepSeek Harness（DSH）左侧侧边栏里的智能体。你打开它，它就能看见你的屏幕，跟你一起看视频、看你打游戏，偶尔在它自己的会话里说一句话；你不打开它，它就在工作区里待命，随时可以被你叫去看一眼东西。

| 能力轴 | 它做什么 | 怎么触发 |
|---|---|---|
| A 实时陪看 | 持续看你的主屏（也听你播放的声音），判断该不该开口 | 你点「开始看屏幕」后，它自己判断；**只在旁座自己的会话里主动说话** |
| B 被叫去看 | 看一下屏幕 / 解读视频 / 给视频做 caption / 写观后感 | 你在任意会话里叫它（四个 `side_seat_*` 工具）；**永远被动** |
| C 记得你 | 口味、观点账本、关系状态、共同经历 | 全程后台；决定 A 轴说什么、什么时候闭嘴 |

默认约每 2 分钟一句（每小时 30 句）。安静档约每 5 分钟一句，话多档约每分钟一句。

## 支持范围

- **DeepSeek Harness `>=0.2.2-rc.5 <0.3.0`**（按 0.2.2-rc.5 开发与核对）。启动时检查版本，不在范围内会给出可读提示，不会崩。
- **Windows + DSH Desktop / Web**。其它系统上实时陪看（A 轴）会直接禁用并说明原因；工作区工具（B 轴）照常可用。
- Node.js 22.19+（DSH 自带）。
- **模型必须能看图**：所选模型的 `inputModalities` 要包含 `image`。不含时设置页和面板会明确报错，不会硬跑。默认 `llm:deepseek-flash`，可在设置里改。

| 依赖 | 是否必须 | 用来干什么 |
|---|---|---|
| 无 | — | 陪看屏幕（A 轴）、看当前屏幕。零外部依赖 |
| ffmpeg | 可选 | 解读 / 标注 / 鉴赏本地视频文件；系统声音的 dshow 兜底 |
| 听写引擎（ASR） | 可选 | 听见台词。不配也能用，只是「听不见台词」 |

不需要你装 Python、Chromium 或模型文件。

## 安装

**推荐：用 Release 里的 `.tgz`**（不需要构建、不需要 git、不需要网络拉源码）。

1. 从 [Releases](../../releases) 下载 `dsh-side-seat-<版本>.tgz` 和 `SHA256SUMS.txt`
2. 先校验（可选但建议）：

   **PowerShell**
   ```powershell
   Get-FileHash .\dsh-side-seat-1.0.20.tgz -Algorithm SHA256
   ```
   **macOS / Linux**
   ```bash
   sha256sum -c SHA256SUMS.txt
   ```

3. 安装：

   ```
   dsh plugin --profile <你的 profile> add ./dsh-side-seat-1.0.20.tgz
   ```

   或者用 DSH 的 **Plugins → Add plugin** 选中这个 `.tgz`。

**从源码目录安装**（改代码、自己调试时用；装的是源码，行为与安装包一致，因为没有构建步骤）：

1. DSH 里 **Plugins → Add plugin**，选择本目录（`dsh-side-seat/`）。
2. 让 DSH 的 plugin_manager 执行 `install_bundle`，`target` 传本目录的**绝对路径**。
3. 命令行：`dsh plugin --profile <你的 profile> add <本目录绝对路径>`

> 源码目录安装会在用户机器上执行包内脚本（本项目没有 `prepare`，所以实际上什么都不跑）。介意的话用 `.tgz`。

**不要手改 profile 里的 `package.json`**——DSH 有专门的安装入口，手改容易把 profile 弄坏。

装完重启 DSH，侧边栏底部（设置旁边）会出现「旁座」。

本包不需要构建：Host 半边是原生 ESM（`index.js` + `src/`），Client 半边是手写的 `window.__ModuleLoader__` 包（`client.js`），运行时只依赖浏览器模块表里的 `react`。

自检（在本目录下）：

```
node test/selfcheck.mjs
```

它会跑纯逻辑单测，并在一个假宿主上走一遍 `apply()`：注册四个工具、校验返回值形态、注册路由、跑一小段观察循环、最后检查卸载干净。

## 怎么用

**陪看（A 轴）**

1. 点侧边栏底部的「旁座」，弹出面板。
2. 点「开始看屏幕」。如果开着「听声音」，浏览器会弹出共享选择器：选整个屏幕，并勾选「共享系统音频」。
3. 它会在旁座自己的会话里偶尔说一句。会话下方一直有状态条，例如：`正在看你的屏幕 · 能听到声音 · 听不见台词 · 已 12 分钟 · 说 3 句 · 暂停 · 停止`。
4. 嫌它烦就点「有点烦」。连续两次之后它会静默 10 分钟。在旁座会话里说「安静看」，它就不主动开口，说「可以说话了」再恢复。

**被叫去看（B 轴）**：在任何会话里直接说就行，模型会调用对应的工具：

| 你说 | 工具 | 输出 |
|---|---|---|
| 看一下我屏幕上这个东西 | `side_seat_look` `target=screen` | 一段带位置的描述，加一句判断 |
| 这段视频帮我解读一下 | `side_seat_look` `target=file` | 带 `[mm:ss]` 时间码的解读（需要 ffmpeg） |
| 给这段视频做 caption | `side_seat_caption` | 每个镜头一行，带时间码，导出 `.srt` / `.csv`（需要 ffmpeg） |
| 写个观后感 / 赏析 | `side_seat_review` | 每句话都带秒数出处；没有出处的句子会被删掉（需要 ffmpeg） |
| 你记得我喜欢什么吗 | `side_seat_profile` | 读、改、删记忆 |

B 轴从不主动：除非这次调用明确要求看屏幕，否则它不会截屏；它也不生成任何音频或视频。

## 设置（设置 → 旁座）

只有一个页面，五个控件：

| 控件 | 默认 | 说明 |
|---|---|---|
| 它是谁 | 温和、话少、有点毒舌的朋友 | 用一句话描述性格，会写进旁座会话的人格段 |
| 朗读 | 女 | 男 / 女 / 关。用浏览器自带的 Web Speech，可以打断 |
| 听声音 | 开 | 能不能听见你播放的声音。关掉就只看画面 |
| 说话频率 | 正常 | 安静约每 5 分钟一句 / 正常约每 2 分钟一句 / 话多约每 1 分钟一句 |
| 观察范围 | 整个主屏 | 「当前窗口」是 P1，这一版仍然按主屏观察 |

页面底部有两个默认折叠的分组：

- **状态**：当前用的截屏后端、视觉模型能不能看图、系统声音来自哪里、听写是否可用、主动发言走的是哪条路径、Harness 版本、记忆存在哪、有没有中文语音、有没有 ffmpeg。另有「清除全部记忆」按钮：确认后会真的删除，并告诉你删了几条。
- **听写引擎（高级）**：可以选「无 / DSH 内置 / OpenAI 兼容 / 自定义命令」。**「试一下」**会现场用 Windows 语音合成生成一句中文样例，然后显示识别出的第一句，或者告诉你具体哪里错了（地址错、密钥错、命令不存在……）。

## 它能看到什么、看不到什么、数据去哪了

**它能看到的**

- 你点「开始看屏幕」之后，它每秒截一张**主屏**。截图只放在内存里，最多保留最近 10 张；暂停或停止时清空，插件退出时销毁。
- 只有当画面真的在变、而且内容值得一说时，它才把一张**缩略图**发给你在设置里选的模型；值得开口时，再发一张接近原尺寸的图。10 分钟里最多调用 20 次视觉模型。
- 开着「听声音」并且你在共享选择器里勾选了系统音频时，它会听你**正在播放的声音**。它在本地算响度、有没有人在说话、是不是在放音乐，这一步不调用任何模型。

**它看不到的**

- 你没有点「开始看屏幕」时，它什么都不看。它不会开机自启，也不会恢复上次的观察状态。
- 它不用麦克风，不做语音输入，也不监听键盘、鼠标或任何全局事件。
- 没有配置听写引擎时，它**听不见台词**。状态条会直接写「听不见台词」，它说的话里也不会出现任何台词。
- 截屏失败、模型不能看图或者断网时，它会报错并停止发言，不会编造「我看到你在……」。

**数据去哪了**

| 数据 | 去向 |
|---|---|
| 截图 | 只在内存里。会发给你自己配置的模型服务（经 DSH 的附件服务转成图片引用），不会发给任何第三方，也不会被保存，除非你明确要求 |
| 音频 | 只在内存里，识别完就丢，只有识别出的文字进入时间轴。默认引擎是「无」，音频不会离开本机 |
| 云端听写 | 只有你自己选了「OpenAI 兼容」并确认上传后，才会上传**检测到人声的那 3–5 秒片段**，上传到你填写的地址。从本地视频文件转写出的台词会标注「来自云端转写」 |
| 自定义命令听写 | 片段会短暂写到系统临时目录交给你的命令，命令跑完立刻删除 |
| 听写密钥 | 存在 DSH 凭据服务里（`$DSH_HOME/.credentials.yaml`，引用名 `SIDE_SEAT_ASR_API_KEY`）。不写进设置、不写进 cordis.patch.yml、不写进日志；设置页只显示「已配置 / 未配置」 |
| 记忆（口味、观点、关系、共同经历、沉默记录） | 存在 DSH storage 的 `side-seat` 域；宿主不提供时退回 `$DSH_HOME/plugins-data/side-seat/memory.json`。可以在设置页一键清除 |
| 设置 | 存在 DSH 设置的 `side-seat` 命名空间；宿主没有把这个命名空间暴露给浏览器时，退回 `$DSH_HOME/plugins-data/side-seat/settings.json` |

## 关于游戏

在游戏里说错话，比不说话糟得多。所以游戏场景默认**只夸不教**：

- 它要连续观察 30 秒以上，才开始判断你在干什么。单看一帧不算数。
- 它主动开口只限两类：一是明确、能验证的错误（资源见底、防线明显空着、没开生产），二是漂亮的操作。
- 它给的策略性建议都会带理由，并且会说「还有一个选项是……」，不会只给一个命令式的答案。
- 第一版不保证能给钢铁雄心这类深度策略游戏提出正确建议。它能做到的是：看懂当前界面在干什么，给出保守、不误导的观察。

它不是教你打游戏的，它是坐在旁边看你打的人。

## 主动发言：三条路径（当前用的是哪条见「设置 → 旁座 → 状态」）

旁座要在你没说话的时候出现在聊天流里。实现上有三条路径，按顺序降级：

1. **路径一 · 自己写进会话**（默认先试）：旁座自己生成那句话，直接往自己的会话里 append 一条 `assistant/message`（`surfaceOp: 'append'`），不依赖 agent loop 被唤醒。
2. **路径二 · 触发一轮对话**：往会话里 followup 一条标着「旁座内部提示」的 user 消息，让 agent loop 跑一轮。语义更自然，但历史里会多出一条你没说过的话。
3. **兜底 · 客户端浮层**：在界面上显示一张「旁座此刻在想：……」的卡片，点一下进入对话。不如真消息，但不会出错。

不管走哪条路径，朗读都在浏览器里进行。路径一能不能被 Web 端正常渲染成一条助手消息，需要在实机上确认。确认后，可以在设置的 `speakPath` 里锁定一条路径（`auto` / `append` / `followup` / `overlay`），也可以用环境变量 `DSH_SIDE_SEAT_SPEAK_PATH`。

## 说话预算

预算的算法是 `floor(观察时长(小时) × 每小时预算) − 已说句数`，暂停的时间不算。按默认的 30 句每小时，大约**每 2 分钟就攒够一句的额度**；安静档（12）约 5 分钟，话多档（60）约 1 分钟。预算为 0 时，它连视觉模型都不调用，所以几乎不花钱。

## 零冲突

- 工具名只用 `side_seat_*`，不会与 `video_*`、`reaction_*`、`office_*`、`session_*` 重名。
- 只注册 list 类型的界面槽位：`sidebar.footer.action`、`settings.section`、`shell.overlay`、`conversation.composer.dock`。不占用任何 single 槽位。
- 设置只写 `side-seat` 命名空间，存储只用 `side-seat` 域。
- 不调用 `ctx.tools.restrict`，不覆盖其他插件的 system prompt 段（人格段只注册在旁座自己的 agent 作用域里），不改任何会话的 provider/model。
- 不注册全局快捷键，不挂钩子，不监听键盘鼠标。
- 只在你点入口后创建或复用自己的会话，不会劫持你当前的会话。
- dsh-video-vision、dsh-videostory 不是依赖；两者可以和旁座同时安装，工具列表里不会出现重名。
- 卸载时会停掉所有定时器，回收常驻的 PowerShell 和 ffmpeg 子进程（Windows 上用 `taskkill /T /F` 收掉整棵进程树），释放捕获句柄和声音共享，侧边栏的指示点也会消失。

## 已知限制

- 「当前窗口」观察模式是 P1，这一版只看主屏。
- 后端 B（ffmpeg gdigrab）截的是整块虚拟桌面。多屏时请用后端 C（PowerShell，只截主屏），可以设环境变量 `DSH_SIDE_SEAT_CAPTURE=pwsh` 强制使用。
- 系统声音要靠浏览器的 `getDisplayMedia`（需要你在选择器里勾选「共享系统音频」），或者 Windows 的「立体声混音」录音设备（需要 ffmpeg，默认是关闭的）。两者都不可用时，它就只用画面工作，状态条会写明听不见。
- 本插件里有一部分宿主接口来自对同类插件和官方文档的核对，**仍需在你的机器上现场复核**，清单见 [docs/DETAIL.md](docs/DETAIL.md) 的「M0 现场核实清单」。

## 环境变量（排障用）

| 变量 | 作用 |
|---|---|
| `DSH_SIDE_SEAT_CAPTURE=electron\|ffmpeg\|pwsh` | 强制使用某个截屏后端 |
| `DSH_SIDE_SEAT_FFMPEG` / `DSH_FFMPEG_PATH` | 指定 ffmpeg 的路径 |
| `DSH_SIDE_SEAT_AUDIO_DEVICE` | 指定 dshow 录音设备名 |
| `DSH_SIDE_SEAT_MODEL` | 覆盖视觉模型（写成 `providerId:modelId`） |
| `DSH_SIDE_SEAT_SPEAK_PATH` | 锁定主动发言路径 |
| `DSH_SIDE_SEAT_DEBUG=1` | 输出调试日志（stderr） |
